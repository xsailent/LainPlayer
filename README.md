## LainPlayer: плеер для социальной сети lainlife.org

TUI плеер на Python, загружающий треки с сайта lainlife.org и воспроизводящие их в mpv

## Из нововедений:

1. Вход в свой личный аккаунт lainlife.org
2. Загрузка и воспроизведене треков из списка
3. Весь интерфейс переписан на textual заместо pytermgui
4. Убраны ненужные комментарии
